# PrimeInvest — Landing Page

Одностраничный адаптивный лендинг под рекламный запуск **PrimeInvest**, выполненный на чистых **HTML, CSS и JavaScript** без сборщиков с использованием методологии **BEM** и подхода **mobile-first**.

## Что реализовано

- **Hero + Sticky CTA**: заголовок, подзаголовок, кнопка `Начать сейчас` и липкая плашка CTA (снизу на мобильных экранах, сверху при скролле на десктопе).
- **Таймер-стимул (15 минут)**: обратный отсчёт на 15 минут с момента входа на страницу (сохраняется в `sessionStorage`). По завершении таймера кнопки CTA меняют текст на `Последний шанс`.
- **Слайдер отзывов**: 4 карточки с фото, именем, ролью и текстом отзыва. На мобильных и планшетах доступен свайп, на десктопе — стрелки и точки навигации.
- **FAQ-аккордеон**: 6 вопросов с плавным раскрытием/сворачиванием; одновременно открытым может быть только один пункт.
- **Блок «О нас»**: адаптивный блок с изображением, текстовым описанием проекта и ключевыми акцентами.
- **Многошаговая форма лидогенерации**:
  - **Шаг 1**: имя и email с валидацией без перезагрузки страницы.
  - **Шаг 2**: выбор страны, телефон с маской под страну, кнопка возврата на первый шаг и чекбокс согласия.
  - После успешной отправки открывается модальное окно **«Заявка принята»**.
- **Адаптивность, производительность и SEO**: breakpoints `360px`, `768px`, `1024px`, `1280px+`, `loading="lazy"` для изображений, заданные размеры/пропорции, `<title>`, `<meta name="description">` и иерархия заголовков `H1–H3`.

## Как запустить локально

Проект не требует установки зависимостей (`npm install`) и сборки:

1. Клонируйте репозиторий или скачайте архив с проектом:

```bash
git clone [https://github.com/Evgeniy45/PrimeInvest](https://github.com/Evgeniy45/PrimeInvest)
cd ВАШ_РЕПОЗИТОРИЙ
```

2. Откройте `index.html` напрямую в браузере **или** запустите локальный сервер:

- **VS Code**: установите расширение _Live Server_, нажмите правой кнопкой по `index.html` и выберите _Open with Live Server_.
- **Через терминал (если установлен Python)**:

```bash
python -m http.server 5500
```

После этого откройте в браузере `http://localhost:5500`.
